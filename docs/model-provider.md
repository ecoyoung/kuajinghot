# 模型配置与首批处理

当前自定义 provider 使用 OpenAI 兼容接口：

```dotenv
LLM_BASE_URL=https://airouter.ziggie.cn/v1
LLM_API_KEY=填入自己的密钥
LLM_MODEL=grok-4.6
LLM_EXTRA_JSON={}
LLM_JSON_MODE=true
LLM_TIMEOUT_MS=240000
MODEL_CALLS_ENABLED=true
```

实际密钥只保存在忽略提交的 `.env`（文件权限 0600），没有写入源码、示例配置、文档或 Git 历史。各处理步骤使用框架的 `default` 模型，所有调用仍经过请求回执与预算熔断。

2026-10-09 已通过 provider 的 `/models` 接口确认模型可用。运营者授权“全部处理”后，首批 121 条资料全部完成：92 条通过分析并可在“全部动态”阅读，其中 13 条精选；29 条预筛排除；失败和待处理均为 0，分析、提取、归组与综述队列无待办。精选包含历史日期的资讯，当日首页展示受日期窗口约束。

120 条正文完成读取（包括本批 Sea 的 8 份官方 PDF），1 条 HMRC 资料正文未能确认，按来源摘要分析并保留 `unconfirmed` 状态。Sea PDF 使用本地一次性提取辅助流程；常驻框架的 PDF 正文提取仍需另行验证或配置相应提取服务。没有开启任何来源的公开全文权限。

provider 部分请求超过默认 120 秒，故增加可选 `LLM_TIMEOUT_MS`；未配置时保留原默认超时。处理过程中结果不明的请求按既有回执恢复机制处理，没有绕过回执或预算。最终所有模型回执均为 completed，批处理进程已停止。

批处理期间临时提高请求数量预算，结束后已恢复每分钟 10 次、每小时 20 次、每日 30 次。此限制以请求次数计，不是货币金额上限，无法据此推算实际费用。自动采集、飞书和 IndexNow 仍关闭，未运行常驻 worker。

正式部署需配置生产数据库、会话密钥和网络出口，确认持续运行预算后启动 worker；运行 worker 会消费待办队列。模型密钥由部署者自行填写，GitHub 仓库不包含本机新闻数据库和运行日志。
