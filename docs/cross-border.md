# 跨境电商热点：定制与上线确认

本地预览草案，2026-10-09。站名「跨境电商热点」与 MCP 前缀 `kuajinghot` 均待运营者确认；上游框架的内部包名保留以便维护。

## 内容范围

优先平台规则、平台体量与增长、大品牌出海策略；补充物流履约、海外仓、支付、税务关务、广告、独立站和经营实践。页面分类：平台规则、市场增长、品牌出海、经营服务、经营实践、行业解读。后两类为评论类，沿用框架日报去重规则。RELEASE 为 null，不再显示“新模型”指标。

规则保留站点、适用对象、生效日期和过渡期；市场数据区分 GMV、收入、利润、集团和分部口径、币种及统计期间；品牌案例以已发生动作和可核验结果为依据。维持七种内容类型的五轴权重，仅将规则、方法、研究类型改为电商语义。原 T1 60、T1_5 65、T2 76 门槛没有修改，尚未在新行业校准。

## 信源

首批信源已按运营者委托选取并接入：21 个配置，16 个启用并完成实抓，5 个因网络/日期问题暂缓；首次入库 121 条带来源日期的原始资料。平台与品牌、监管的一手渠道与 T2 媒体分级使用，全文权限关闭。完整名单、覆盖边界和后续项见 [信源登记](source-register.md)，核验快照见 `industry/source-audit.json`。

公开接口版本升为 5.0.0：分类与内容类型的语义已改为跨境电商，旧客户端需按新分类重新接入。

已有数据库不会自动删除原 AI 信源或资料。升级旧站时先在后台暂停旧源、处理旧内容，再导入新源；本次没有破坏性迁移。seed 只补入新的 id，旧记录仍需从后台启停或更新；不能仅靠删除 sources.json 条目停用旧源。本地预览库已注册首批渠道，并按核验结果启停先前五项。

## 需要运营者决定

1. 正式站名、Logo、域名、运营主体、公开邮箱和上线时间；上线前再确认分类 key、主题 slug 与 MCP 前缀，接入后避免改动。

3. 哪些重要、哪些噪声，标注 100–200 条真实资料为该选/不该选，运行 SelectBench 或 eval-selection 校准。示例均为虚构资料，不是实际规则。
4. 使用规则、数据使用授权、隐私说明、日志期限、反馈处理、第三方服务与联系方式。site/pages 两页保持待确认状态。
5. 持续运行的模型请求预算与费用上限、向量服务、公众号/X 采集预算与推送；provider 与模型已按运营者配置落实。
6. 日报北京时间 08:00、周一 10:00、月初 10:30 是否合适。

## 本地检查

使用 Node 24 与 PostgreSQL 17。测试库必须以 `_test` 或 `_ci` 结尾，运行 `npm run typecheck`、`DATABASE_URL=... npm test`、`npm run build -w @aihot/web` 和 `node --test apps/web/tests/*.test.ts`。启动 API 和 web 后运行 `node scripts/smoke.ts --base http://localhost:3000`。测试期间采集、模型、飞书和 IndexNow 开关均保持 false；真实模型验证是运营者配置 provider 后单独运行的本地处理任务。

配置静态页、RSS/API/MCP 与分享图都从同一份站点/行业配置读取；根目录固定文件中的占位符由框架运行时替换，无需写死本地域名。
